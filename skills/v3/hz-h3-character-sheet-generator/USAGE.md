# Usage Guide: HZ MiniMax H3 & Omni Flash Character Sheet Generator

## What It Does
Creates specialized multi-view character reference sheets for **MiniMax H3 (`Ref2VA`)**, **p-h3**, **Pika**, and **Omni Flash** across 5 layouts, with **Full-Body Face-Masking (`face_mask_mode`) ON by default** so video models pull facial likeness strictly from high-resolution close-up portraits.

## Example Prompts

### 1. Omni Flash / H3 Rapid Identity Sheet (Type 1)
> Use `hz-h3-character-sheet-generator` to create a Type 1 (`omni-rapid`) sheet for a weathered 45-year-old cowboy in a dusty brown leather duster. Keep face-masking ON for the full-body view.

### 2. H3 Master Triad + Macro Details (Type 2)
> Use `hz-h3-character-sheet-generator` in Type 2 (`h3-master-triad`) layout from my attached character photo `<Picture 1>` so I can use it as `<Subject 1>` in MiniMax H3 Ref2VA.

### 4. 10-Expression Grid for Lip-Sync (Type 4)
> Use `hz-h3-character-sheet-generator` to create a Type 4 (`expression-grid`) sheet with 10 emotions for my cute pink 3D monster character on a dark slate background.
